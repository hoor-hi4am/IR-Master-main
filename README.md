# 📚 NLP Visual Learning Playground

A **web-based interactive educational tool** for visualizing core **Natural Language Processing (NLP)** and **Information Retrieval (IR)** concepts.

Built using **HTML, CSS, and JavaScript (Vanilla JS)**.


## 🧠 Features

### 🔤 Text Processing

* Tokenization (raw & clean)
* Stop words removal
* Stemming (Porter-like algorithm)
* Lemmatization (dictionary-based)
* Text normalization

### 🔎 Information Retrieval

* Boolean Retrieval (AND / OR / NOT)
* Inverted Index visualization
* Bag of Words model
* TF-IDF + Cosine similarity ranking

### 🧮 Similarity & Matching

* Levenshtein Edit Distance
* Jaccard Similarity
* Soundex phonetic matching

### ✍️ Spelling Correction

* Dictionary-based spell checker
* Edit distance suggestions

### 📊 Dataset Manager

* Upload custom corpus
* Load demo dataset
* Real-time indexing of documents

### ✨ UI Features

* Animated floating particles background
* Interactive sidebar navigation
* Real-time visualization of algorithms
* Responsive modern UI

## ⚙️ How to Run Locally

### Option 1:

Just open:

```

```

### Option 2 (VS Code):

1. Open folder in Visual Studio Code
2. Install Live Server extension
3. Click **Go Live**

---

## 🌐 How to Deploy

### Deploy on GitHub Pages:

1. Push project to GitHub repo
2. Go to **Settings → Pages**
3. Select branch: `main`
4. Click Save
5. Get your live link 🎉
